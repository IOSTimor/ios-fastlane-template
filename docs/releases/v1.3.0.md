# v1.3.0

One-command local IPA export is now available through Homebrew.

```bash
brew tap IOSTimor/ios-release
brew install ios-fastlane-template
ios-fastlane-template build /path/to/your/ios-project
```

For existing installations, run `brew update` and `brew upgrade ios-fastlane-template`.

- Install Ruby, fastlane and the pinned local builder alongside the CLI.
- Discover iOS workspaces, application schemes and signing settings directly from Xcode.
- Export locally without installing the release template or filling `.env`.
- Prompt for ambiguous apps, support dry-run and explicit CI overrides.
- Include installer, configuration, asset validation and release workflow reliability fixes since v1.2.1.

The app still needs working Xcode signing and dependencies. This command exports an IPA; it does not upload the app.
