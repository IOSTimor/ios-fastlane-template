# v1.4.0

Unified release commands are available from the Homebrew CLI:

```bash
brew update
brew upgrade ios-fastlane-template
iosipa testflight /path/to/app
iosipa metadata /path/to/app --screenshots
iosipa submit /path/to/app --version 2.0.0 --build-number 42
```

The commands invoke existing project release lanes. Configure `fastlane/.env` once and prepare assets before uploading. Submit selects an explicit existing build, reuses remote assets by default, and defaults to manual release after approval. Dry-run does not authenticate, build, upload, submit or install dependencies. Existing `build` and the original CLI name remain supported.
