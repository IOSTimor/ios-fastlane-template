# v1.3.1

Use the shorter `iosipa` command after upgrading:

```bash
brew update
brew upgrade ios-fastlane-template
iosipa build /path/to/your/ios-project
```

The original `ios-fastlane-template` command stays available. Both names use the same launcher and builder; packaging, signing and output behavior are unchanged. The Homebrew package name remains `ios-fastlane-template`.
